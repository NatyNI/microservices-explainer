# Microservices Explainer

Schematică interactivă Auth (DEV) — login browser + revoke acces.

## Live (GitHub Pages)

După deploy: **https://nicolaenati.github.io/microservices-explainer/**

## Local

Deschide `index.html` în browser (dublu-click).

## Conținut

- **Login browser** — theMarketerID → sesiune în app sendm
- **Revoke acces** — eliminare din auth portal → deconectare în app

## GitHub Pages setup

1. Repo: `microservices-explainer` pe contul personal GitHub
2. **Settings → Pages →** Branch `main`, folder `/ (root)`
3. Fișierul `index.html` de la rădăcină = homepage
